# Evolvo.cz - Dasa Ouhrabkova

Moderní multipage webová prezentace pro osobní značku **Dasa Ouhrabkova** - vzdělávací kurzy pro úředníky, sociální pracovníky a soukromé firmy.

## 🎯 O projektu

Tento web nabízí profesionální prezentaci vzdělávacích kurzů v české jazyce s moderním, čistým designem ve světlých barvách. Web je postaven na Vue 3 + Vite.

## 🚀 Technologie

- **Vue 3** - Moderní progresivní JavaScript framework
- **Vue Router** - Navigace mezi stránkami
- **Vite** - Rychlý build nástroj
- **CSS3** - Responzivní design

## 📦 Instalace

```bash
# Nainstalovat závislosti
npm install

# Spustit vývojový server
npm run dev

# Vytvořit produkční build
npm run build

# Náhled produkčního buildu
npm run preview
```

## 🌐 Struktura stránek

- **Domů** (`/`) - Úvodní stránka s přehledem služeb
- **Kurzy** (`/kurzy`) - Kompletní nabídka kurzů pro všechny cílové skupiny
- **O mně** (`/o-mne`) - Představení lektorky a její filozofie
- **Recenze** (`/recenze`) - Hodnocení od spokojených klientů
- **Kontakt** (`/kontakt`) - Kontaktní formulář a kontaktní údaje

## 🎨 Design

- Světlé, profesionální barvy (modrá, bílá)
- Moderní SVG logo s motivem vzdělávání
- Responzivní design pro mobilní zařízení
- Čistý a přátelský vzhled
